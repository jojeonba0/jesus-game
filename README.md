# ✝️ 예수님 게임

실시간 마피아 변형 게임입니다. 운영자가 방을 만들고, 참가자는 코드·QR·링크로 들어옵니다.

## 주소
- `/` 첫 화면 (코드 입력 / 운영자)
- `/admin` 운영자: 방 만들기, 코드·QR·링크, 총 인원 설정(다 차면 입장 마감), 랜덤/직접 역할 배정, 낮↔밤 전환, 제외/복귀, 투표, 채팅 모니터, 기록
- `/join?room=코드` 참가자
- `/preview` 미리보기: 한 화면에서 운영자 1명 + 참가자 여럿으로 시험해 보기 (서버 저장소 없이 브라우저 안에서만 동작)

## 규칙
| 역할 | 승리 조건 | 능력 / 밤 투표 |
|---|---|---|
| 예수님 (1명, 모두에게 공개) | 바리새인과 배신자가 모두 제외됨 | 밤에 "오늘 밤 살인 무효화" (횟수는 운영자가 1·2·3번·매일 밤 중 선택). 아침 투표에서 2표, 아침 투표로는 안 죽음 |
| 제자 | 예수님 팀이 이기면 함께 승리 | 제자 표 상위 N명(기본 2명)은 그날 밤 안 죽음 (경계에서 동률이면 그 사람들은 빼고) |
| 바리새인 | 예수님이 제외됨 | 바리새인 표 상위 N명(기본 2명)이 그날 밤 죽음 (경계에서 동률이면 그 사람들끼리 재투표) |
| 배신자 | 바리새인과 제자가 모두 제외되고 예수님과 배신자만 남음 | 배신자 표 상위 N명(기본 1명)이 그날 밤 죽음 (경계에서 동률이면 재투표) |

- **밤 투표 인원**: 운영자가 게임 시작 전에 제자가 살리는 / 바리새인·배신자가 죽이는 인원을 0~5명으로 정합니다. 0명이면 그 역할은 밤 투표를 하지 않습니다.
- **되돌리기**: 운영자가 "↩️ N번째 밤으로 되돌리기"를 누르면 그 밤의 아침 발표 직전으로 돌아갑니다. 그 뒤에 죽은 사람은 살아나고, 밤 투표가 기존 표 그대로 다시 열립니다. 최근 10번의 밤까지, 게임이 끝난 뒤에도 됩니다.
- **강제 종료**: 운영자가 게임을 끝내면, 살아 있는 바리새인이 그 외 사람(예수님·제자·배신자)보다 많을 때 바리새인 승리, 적거나 같으면 예수님+제자 승리로 판정합니다.
- 모든 투표는 방에 들어올 때 쓴 이름(본명)으로, 살아 있는 누구에게나 할 수 있습니다.
- **아침**: 채팅이 닫히고 직접 대화합니다. 운영자가 아침 투표를 열면, 과반수를 받은 1명만 죽습니다.
- **밤**: 팀별 채팅방과 밤 투표가 열립니다. 운영자가 아침으로 넘기면 투표가 마감되고 결과가 발표됩니다.
  재투표가 필요하면 밤이 유지되고, 운영자가 재투표를 마감하거나 무작위로 정합니다.
- **채팅 이름**: 모두 "익명+번호"로 보이고, 예수님만 "✝️ 예수님 (이름)"으로 보입니다. 번호는 방마다 무작위입니다.
- 운영자가 배신자가 들어갈 방(예수님·제자 / 바리새인 / 배신자 전용)을 하나 이상 고릅니다.

## Vercel 배포
1. vercel.com → **Add New → Project** → 이 저장소 Import → 설정 그대로 **Deploy**.
2. 프로젝트의 **Storage** 탭에서 저장소를 하나 연결합니다. 둘 중 아무거나 됩니다.
   - **Supabase** (연결하면 `POSTGRES_URL`이 자동으로 들어옴, 표는 처음 쓸 때 자동 생성)
   - **Upstash for Redis** (`KV_REST_API_URL`, `KV_REST_API_TOKEN`이 자동으로 들어옴)
3. **Deployments → ⋯ → Redeploy** 로 다시 배포해 연결을 반영합니다.
4. `https://내주소/api/health` 를 열어 `"상태": "✅ 정상 연결됨"` 이 나오는지 확인합니다.

저장소를 연결하지 않으면 게임 화면에 "서버 저장소가 연결되지 않았어요"가 표시됩니다.
Supabase에서는 게임 데이터가 API로 공개되지 않는 `jesus_game` 스키마에 저장됩니다.

### 구조
- `public/` 화면 (Vercel이 그대로 제공)
- `public/engine.js` 게임 규칙 + 요청 처리 (서버와 미리보기가 같은 코드 사용)
- `api/action.js` 모든 게임 요청 (`POST /api/action`), `api/qr.js` QR 이미지
- `lib/store.js` 저장소 (Supabase 또는 Upstash Redis, 방은 마지막 변경 후 24시간 보관)
- `api/health.js` 연결 상태 확인 (`GET /api/health`)
- 화면은 1.2초(밤)~2.5초(낮)마다 새 상태를 받아옵니다. 바뀐 게 없으면 저장소 요청 1번만 씁니다.

## 로컬에서 실행
```
npm install
npm start      # http://localhost:3000  (저장소 환경변수가 없으면 메모리에 저장)
```
